# E-024 Report Gate 必在报告生成前执行

## 场景
- 用户在 Step 0.5 声明仅做"资格 + 商务"（不含技术）
- Stage 2 资格审核 + Stage 3 商务评分已完成
- 主体审核完成后、报告生成前

## 期望行为
1. **必须**执行 [Report Gate]｜历史案例反向查漏（在 Stage 3 后、报告生成前）
2. **必须**落盘 `_work/report_gate.md`（包含入口路径 / 读取时间戳 / 扫描清单 / 命中或无命中声明 / 读取失败声明）
3. **未落盘** `_work/report_gate.md` → 报告**不得落盘**
4. 不强制要求"历史案例提醒"小节出现在报告中（仅命中真实案例时才插入）

## 不允许行为
- 跳过 Report Gate 直接生成最终报告
- 仅在聊天中口头声明"已扫描案例库"而不落盘 `_work/report_gate.md`
- 在未命中案例时插入空表 / 占位符
- 把 Report Gate 移到 Stage 1.0 / Stage 1.5.1 / Stage 2.6 / Stage 5 任一阶段
