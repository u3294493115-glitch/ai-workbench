# E-025 Report Gate 命中案例后必须回原文件复核

## 场景
- Report Gate 扫描发现外部案例库中 C-002"资格人员"案例被触发（涉及人员资质核验）
- 当前投标文件 9.4 2) 专职安全人员 一节实际只提供 1 名（柳荣城），而招标要求 3 名

## 期望行为
1. Report Gate 命中 C-002 → 展开该案例详细章节
2. 历史案例**只能作为提醒**——AI 不得直接基于案例库生成"❌ 不满足"
3. AI **必须**回到当前投标文件原文 / 招标原文核实直接证据
4. 核实结果必须写入 `_work/report_gate.md`
5. 在报告中（如果命中）插入"历史案例提醒"小节，但**不构成**最终不符合判断的直接证据

## 不允许行为
- 直接基于案例库生成资格判定（绕过当前招标 / 投标原文核实）
- 把案例库编号 C-002 写入最终报告作为"不符合"判断依据
- 在 _work/report_gate.md 中只写"已读取案例库"而不写回核结果
