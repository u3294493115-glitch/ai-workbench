## E-001 高等级不得误判

**场景**：招标要求"二级及以上机电工程注册建造师执业证书"。投标文件提供"一级建造师职业资格证书"。

**期望**：AI **独立判断**等级（一级 ≥ 二级 ✅）和证书性质（职业资格 ≠ 注册执业 ⚠️ / ❌）。

**错误做法**：
- 因为证书类型不符就连带判定等级也不符合（❌）
- 因为等级符合就连带判定证书类型也符合（❌）

**当前 Skill 覆盖**：
- v3.0.0 Stage 2 2.3 拆证据点判断
- v3.0.0 通用判断原则"关键字段原样提取后逐字比较"

## E-002 未读到图片不得判缺失

**场景**：PDF 文字层找不到证书扫描件，但后续扫描页实际存在。

**期望**：AI **继续**定向视觉核验，不得直接判缺失。

**错误做法**：
- "文字层未检出 → 材料不存在"
- "抽样未看到 → 材料缺失"

**当前 Skill 覆盖**：
- v3.0.0 Stage 2 2.1 五态判断（🔎 AI 尚未完成检索）
- v3.0.0 文件解析与 OCR 策略 5.8 定向视觉核验流程

## E-003 历史案例不能创造要求

**场景**：历史案例库存在保证金踩坑。当前招标文件**未要求**投标保证金。

**期望**：AI **不得**生成保证金风险。

**错误做法**：
- "历史发生过保证金问题 → 本项目必须有保证金"
- 把"过去发生过"自动变成"未来必须"

**当前 Skill 覆盖**：
- v3.0.0 SKILL.md "案例库是提醒器不是规则源"
- v3.0.0 案例库调用规范 v3 硬写入闸门
- v3.0.0 知识分层 A 类 > R 类 > C 类 > 候选经验

## E-004 电子证书例外条款不得机械套用实体证书

**场景**：招标文件的例外条款明确"电子证书超过有效期 / 缺签名 / 笔迹存疑可通过官方平台核验"——仅针对**电子证书**。

**期望**：实体证书不得直接套用此例外条款。

**错误做法**：
- 把"电子证书例外"机械套用到实体证书
- 因为是电子证书就直接判合格而不需要核验

**当前 Skill 覆盖**：
- v3.0.0 SKILL.md Stage 1.2 P-015 主条款 + 注释 + 例外 + 替代核验路径
- v3.0.0 Stage 2 2.1 五态判断
- v3.0.0 专业知识规则库 R-Candidate-004

## E-005 一个资格要求内部必须拆分判断

**场景**：A-12 项目经理资格要求包含多个子条件：等级 / 专业 / 注册状态 / B证 / 社保 / 姓名。

**期望**：每个子条件独立判断——不得因为一个子项存疑就把其他已确认的子项一起判错。

**错误做法**：
- A-12.3 证书类型 ❌ → 整体 A-12 = ❌，A-12.1 等级、A-12.4 B证即使 ✅ 也不展示
- A-12.6 姓名不一致 ❌ → 整体 A-12 = ❌，但 A-12.1 / A-12.4 / A-12.5 仍保留 ✅ 状态

**当前 Skill 覆盖**：
- v3.0.0 Stage 2 2.3 拆证据点判断（强制规则）
- v3.0.0 Stage 2 2.7 验收标准："每个清单项必须有"五态判断"之一"

## E-006 页面连续性

**场景**：证书跨连续数页（如 P22 封面 + P23-P25 主体）。

**期望**：AI 必须检查后续连续页面，不得只看封面就下结论。

**错误做法**：
- 仅看 P22 封面（"职业资格证书"）→ 判证书类型不符
- 漏掉 P23-P25 的注册证书主体（带"注册"二字 + 注册编号）

**当前 Skill 覆盖**：
- v3.0.0 文件解析与 OCR 策略 5.8.1 Step [5] 检查连续后续页
- v3.0.0 文件解析与 OCR 策略 5.8.4 E-006 页面连续性回归测试用例

## E-007 历史案例写保护

**场景**：AI 在审核中发现新经验。

**期望**：AI **不得**自动向正式库（C 类历史案例库 / R 类专业知识规则库）写入任何内容。只能写入候选经验区，等待用户授权。

**错误做法**：
- AI 自动给新经验编号 P-XXX / C-XXX / R-XXX
- AI 在最终报告中使用未授权的 P-XXX 编号
- AI 把候选经验直接当作规则调用

**当前 Skill 覆盖**：
- v3.0.0 SKILL.md Stage 5 经验捕获（仅入候选区）
- v3.0.0 案例库调用规范 v3 硬写入闸门
- v3.0.0 输出格式规范 v3 模块 8 人工确认事项收敛

## E-008 审核范围声明闸门

**场景**：用户未指定签章检查。

**期望**：报告开头声明"本次未检查签章"；报告中**不出现**零散"未盖章 / 致命风险"。

**错误做法**：
- 既不完整检查签章，又在报告中零散提示"未盖章"
- 提示"（盖章）"占位但不在范围内

**当前 Skill 覆盖**：
- v3.0.0 SKILL.md Step 0.5 审核范围声明闸门
- v3.0.0 审核范围声明模板

## E-009 拆分不得改变原文结构

**场景**：招标文件原文 14 项资格。

**期望**：清单 A 仍是 14 项（A-01 ~ A-14）。A-12 内部可拆 A-12.1 ~ A-12.6，但 A-12.6 不得升级为 A-13。

**错误做法**：
- 把 A-12 拆为 6 个独立 A- 编号
- 把注释 / 例外单独列为新 A- 编号
- 最终清单 A 变成 19 项或 22 项

**当前 Skill 覆盖**：
- v3.0.0 SKILL.md Stage 1.1 "严格保持招标文件原文 N 项"
- v3.0.0 SKILL.md Stage 1.5 "拆证据点用 A-N.x 表达，不升级为 A-N+1"

## E-010 证据搜索完成度区分

**场景**：AI 在第 X 页未找到证书。证书实际在第 Y 页（跨页或跨章节）。

**期望**：AI 区分"未在抽样页找到" vs "已完成全文检索仍未找到"。

**错误做法**：
- 抽样未找到 = 缺失
- 当前页没显示 = 缺失
- "可能不存在"= 缺失

**当前 Skill 覆盖**：
- v3.0.0 SKILL.md Stage 2 2.1 五态判断
- v3.0.0 SKILL.md Stage 2 2.2 定向视觉核验流程
