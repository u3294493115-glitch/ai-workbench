## 九、硬约束提醒

1. v3.2.0 引入的三态 + ❓ 三要素 + 禁止措辞清单是硬约束，不可降级回 🔵
2. frozen_checklist.md 仅为辅助交叉检查；核验条件必须直接来自当前招标原文（**不**以 frozen 逻辑表达式作为语义真值）
3. 资格主表 7 列模板不可简化 / 不可改列顺序
4. 商务 0 分项必须做针对性二次证据搜索；无搜索记录不得判 0 分
5. 一条招标原文可拆多个核验点，但所有核验点必须挂同一原编号；不得凭空增加招标要求
6. 投标实际内容必须基于当前投标文件真实证据 + 页码；不得引用旧报告二手结论；不得用不对应材料替代
